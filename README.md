# EnglishKM

Тренажёр для подготовки к экзамену по техническому английскому.

Сейчас на сайте есть карточки «слово — перевод» в стиле Quizlet: три набора слов из методички и общий набор «Все слова».

Режимы: **Карточки** (переворот, отметки «Знаю / Ещё учу», прогресс сохраняется в браузере), **Тест** (выбор из 4 вариантов), **Письмо** (ввод перевода), **Подбор** (на время) и **Список**. Направление EN → RU / RU → EN переключается кнопкой в шапке.

Сайт статический, без сборки: просто откройте `index.html` в браузере. Слова лежат в `js/data.js`.

## Публикация через GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save. Через минуту сайт будет доступен по адресу `https://dieyoungzz.github.io/englishkm/`.
